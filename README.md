# شحنك DZ ⚡

متجر جزائري لشحن كريدي الألعاب — PUBG UC، فري فاير، موبايل ليجندز، روبلوكس، فورتنايت، بطاقات Steam.

**الرابط المباشر:** <https://islamsiso644-sudo.github.io/shihank-dz/>

## طريقة العمل

1. اللاعب يختار اللعبة والباقة
2. يُدخل معرّف اللاعب — يتم التحقق من الحساب قبل الدفع
3. يدفع مرة واحدة ببطاقة CIB / الذهبية عبر بوابة SlickPay (SATIM)
4. المبلغ يُقسَّم تلقائيًا: **25% المتجر | 75% المورد**
5. الشحنة تُنفَّذ وتصل للحساب مع إيصال ورقم تتبع

## الصفحات

| الصفحة | الوظيفة |
|---|---|
| `index.html` | الرئيسية — الألعاب، الأسئلة الشائعة، الأمان |
| `buy.html` | الشراء في 4 خطوات (باقة ← تحقق ← دفع ← إيصال) |
| `track.html` | تتبع الطلب بخط زمني من 5 مراحل |
| `admin.html` | لوحة المالك (PIN) — إحصائيات، أرباح، محفظة المورد |

## وضع الدفع

الموقع يعمل حاليًا في وضع **SIMULATION** (محاكاة كاملة بدون مال حقيقي، معرّف التاجر `260913767712` مُعد مسبقًا).

للانتقال إلى الدفع الحقيقي (LIVE) عبر واجهة SlickPay Payment Aggregation:

1. أنشئ خادمًا خلفيًا صغيرًا (VPS أو Serverless) يستقبل الطلب ويوقّعه بمفاتيح API
2. **لا تضع مفاتيح API في كود الموقع إطلاقًا** — المتصفح مكشوف
3. عدّل `js/config.js`: `mode: "LIVE"`
4. وجّه `pay()` في `js/app.js` لاستدعاء الخادم الخلفي بدل المحاكاة

## قبل الإطلاق (قائمة تحقق)

- [ ] غيّر `ADMIN_PIN` في `js/admin.js` (الافتراضي للتجربة: 2609)
- [ ] حدّث أرقام التواصل في `js/config.js` (واتساب + هاتف)
- [ ] حدّث الأسعار في `js/data.js` حسب أسعار موردك
- [ ] اضبط `supplierStartBalance` و `lowBalanceThreshold` في `js/config.js`

## البنية

```
index.html  buy.html  track.html  admin.html
css/styles.css        التصميم (نيلي/سيان — تذكرة مثقوبة)
js/config.js          الإعدادات + معرّف SlickPay
js/data.js            الألعاب والباقات والأسئلة
js/app.js             منطق الشراء والتتبع + PWA
js/admin.js           لوحة المالك
manifest.webmanifest  تطبيق PWA قابل للتثبيت
sw.js                 خدمة العمل بدون اتصال
assets/img/           الشعار والأيقونات
```

سجل الطلبات محلي على جهاز الزبون (`localStorage`) — في وضع LIVE انقل السجل إلى الخادم الخلفي.
